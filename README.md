# WARNING

This is my personal repository with lots of opinionated changes, some of which are specific to ICM-45686+QMC6309. I am optimising for low power use and good 9DOF operation.

If you are here by mistake, you probably want to look at upstream repositories instead:

* https://github.com/jitingcn/SlimeVR-Tracker-nRF
* https://github.com/SlimeVR/SlimeVR-Tracker-nRF

If you just want pre-built firmware of these, also check out :

* https://github.com/Shine-Bright-Meow/SlimeNRF-Firmware-CI/releases/tag/latest

# Tracker firmware for SlimeNRF
Firmware for Nordic nRF52 / nRF54L Series SoC.

Please see https://docs.slimevr.dev/smol-slimes for more information and usage.

## Note
This repository only tested with Promicro Stacked Slime and Styria boards, other boards may require additional configuration.
